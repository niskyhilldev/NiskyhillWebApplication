# BAM Niskey Hill Web Application (React)

## Branch Description:

This branch will be utilized for all front-end developments in React going forward. Currently a recreation of admin webpage is housed here utilizing the React framework with Material-UI components

### Development instructions:
After Pulling React branch Run the following:  
 - **npm install** - Provides all necessary dependencies within the node_modules folder. Will need to be done anytime dependencies are updated. ****Must be ran after initial pull.****

 - **npm run dev** - will host the admin webpage locally, done

### Primary Sections:
- **Components** - Main location for development, houses .jsx files for major React components

- **api** - Houses .js files for any API calls done to the back-end 

- **App.jsx** - Main layout for the admin page, components are utilized here to produce the layout of the page
